# VHDL Netlist Levelizer

A Python utility that computes topological gate-level depths for VHDL netlists. It supports both custom external packages (component libraries) and standalone standard VHDL netlists.

---

## 1. Prerequisites

- Python 3.x installed on your system.
- Required Python package: `networkx`

To install the required library, run the following command in your terminal:

```bash
pip install networkx
